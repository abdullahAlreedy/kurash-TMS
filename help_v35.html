Kurash Tournament Manager - Help v35.6.5

Note: Main help is now available inside the application as a popup from the top Help button. This file is kept only as an optional printable/manual page.

1. Recommended Tournament Flow

  1. Open Home.
  2. Create a Local Tournament for offline-first operation, or connect a server and use Create on Server.
  3. Open Settings and confirm tournament type, Gillams, weights/groups, durations and referee assignment rules.
  4. Add/import players in Players.
  5. Add/edit referees only in Referees.
  6. Use Referee Management for assignments, final pool, conflicts and evaluations.
  7. Generate the draw, then operate the Scoreboard.

2. Hybrid Offline/Server Mode

  • Offline-first: the program can run without a server.
  • Server optional: enter the URL in Home, then Connect/Test, Load Current, or Sync Now.
  • Unsynced changes: if you work offline, export a JSON backup and sync later.

3. Home vs Settings

  • Home: server connection, tournament creation/loading, backup/restore, readiness check.
  • Settings: rules/config only. No server settings should be managed there.

4. Referees vs Referee Management

  • Referees tab is the only place for adding, editing and deleting basic referee data.
  • Referee Management is only for assignment, final pool, evaluation and conflict review.

5. Scoreboard

  • Space starts/stops the timer unless typing in an input.
  • Use withdrawal buttons for no-show/withdrawal scenarios.
  • Double withdrawal = No Contest, no winner, no points, and bracket slot becomes empty.

6. Backup

  • Use Export JSON Backup before, during and after the tournament.
  • Use Restore JSON Backup to recover a tournament if a browser/server issue occurs.
  • Use CSV export for league standings when needed.

7. Troubleshooting

  • Black screen: use the latest v35.5 files and check the browser console if an old cached file is still loading.
  • Server not connected: continue offline and export JSON backup.
  • Scoreboard not updating: use Sync Now and reload scoreboard from the same server URL.

8. In-App Help Popup

  • Use the top Help button inside main_web_v35.html.
  • The popup combines the old Help tab information, the external manual, scoreboard controls, withdrawal rules, referee evaluation, league standings, and troubleshooting.
  • You do not need to leave the program during a tournament.

9. v35.1 Small Operating Updates

  • Match Duration: Settings now has separate manual duration inputs for Men and Women. Use 0 to keep category defaults.
  • Seed Privacy: In Players, use Hide seed in public views/reports to keep seed stored internally while hiding it from public reports.
  • Player Sorting/Search: Players can be searched by any visible information and sorted by original order, affiliation/country, weight/group, seed, age group, sex, or name.

v20 Scoreboard Controls Hotfix

  • Spacebar: Start / Stop timer, except while typing in an input field.
  • Single click on timer: Start / Stop timer.
  • Double click on timer: manually edit the match time.
  • Gillam / age group / weight: enlarged on the scoreboard for better visibility.

v24 Referee Management Update

Referee Management is now integrated inside Main Web. Use the Referee Management tab for assignments, final referee pool, evaluations, conflict review, and performance profile. The separate referee management file is legacy/optional.

External Referee Management

The main web Referee Management tab is for normal in-app use. For large tournaments, open referee_management_screen_v35.html and give it to the Head of Referees. It must connect to the backend server and load the current tournament before assignments appear.

V28 Referee Management Update

  • Integrated Main Web and the external Referee Management screen now both support evaluating Main Referee, Judge 1, and Judge 2 for every bout.
  • External evaluations are saved to the same server tournament and will appear in Main Web after loading or live sync.
  • Match Assignment layouts were condensed to reduce horizontal scrolling during presentation or committee use.

v35.2 Settings & Players Update

  • Match Duration: Men and Women durations now use small minute and second number boxes with arrow controls and typing support.
  • Seed privacy: the Players table has a checkbox beside the Seed header. When checked, the seed values are hidden from the table while remaining saved internally.
  • Players sorting/search: players can be searched and sorted by affiliation/country, weight/group, seed, age group, sex, or name.

v35.3 Draw Randomization & Seed Rule

  • Seed > 0: seeded players are distributed apart according to seeding logic.
  • Seed = 0 or empty: treated as unseeded.
  • No seeded players: every Generate Draw click creates a fresh random shuffle.
  • Mixed seeded/unseeded group: seeded players keep seeded distribution, while all seed 0/empty players are shuffled randomly into the remaining slots.
  • Seed privacy: hiding Seed in the Players table does not affect saved seed values or draw logic.

Delegation Data Review & Sign-off

The Delegation Sign-off workflow allows each affiliation or country representative to review the final player list before the official draw.

  • Use the Delegation Sign-off tab inside Main Web/Admin to review, monitor, and sign from the admin device.
  • Use delegation_signoff_v35.html as a standalone tablet-friendly signing page.
  • Each approval captures representative name, confirmation, signature, timestamp, player snapshot, approval ID, and version.
  • The approval document can be opened and printed or saved as PDF for the tournament archive.
  • Generate Draw displays a warning if any affiliation has not signed, but it does not hard-block the draw in this version.
