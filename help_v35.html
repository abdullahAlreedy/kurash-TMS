Kurash Tournament Manager - Help v35.6.7 Patch 4

Official help and version notes for the independent Kurash TMS platform. Production URL: https://tms.kurash-tms.com.

1. Main Pages

  • Main Web: tournament setup, players, referees, draw, reports, integrated scoreboard.
  • Online Scoreboard: Gillam operation and result saving.
  • Player Screen: public/current/next bout display.
  • Referee Screen: referee assignment display.
  • Referee Management: head-referee assignments, final pool, evaluations.
  • Delegation Sign-off: tablet-friendly review and approval before draw.

2. Official URLs

  • TMS: https://tms.kurash-tms.com
  • API health: https://tms.kurash-tms.com/api/ping
  • File management: https://files.kurash-tms.com
  • Saudi Kurash API: https://api.saudikurash.sa/

3. Recommended Tournament Flow

  1. Create or load a tournament from Home.
  2. Confirm Settings: tournament type, Gillams, weight/group mode, durations, bye allocation, referee assignment mode.
  3. Add/import players in Players.
  4. Add/edit referees in Referees.
  5. Complete Delegation Sign-off where required.
  6. Generate the draw and review warnings.
  7. Use Referee Management for assignment/final pool/evaluation.
  8. Operate bouts from the Online Scoreboard and monitor reports.

4. Server and Sync Rules

  • Sync Now intentionally pushes local Main Web data to the server.
  • Automatic refresh should not overwrite unsynced local edits.
  • Since v35.6.7 Patch 1/2, result and referee-operation saves use merge-safe routes where possible.
  • Use /api/sync/status to confirm mergeSafe: true.

5. Merge-Safe Saving - v35.6.7

  • Patch 1 server-side merge-safe protection, revision counter, single-bout save, assignment save, evaluation save, final-pool save.
  • Patch 2 client-side save routing from Scoreboard, Main Web, and Referee Management to reduce full-snapshot overwrites.
  • Patch 3 URL/version/help cleanup and default server URL finalization.

6. Scoreboard Notes

  • Online Scoreboard should save bout results through /api/bout/:no/save.
  • Fullscreen-breaking alerts were replaced by internal messages/toasts/glow behavior.
  • Timer/Jazoh half-time logic uses the initial fight duration source from Settings/Schedule.
  • Use End & Next on the Online Scoreboard when progressing through bouts.

7. Draw and Bye Rules

  • First-round bye advances the player by one round only; it must not jump a player directly to finals.
  • Bye allocation setting supports: top seeds first, weighted random by seed, or equal random chance.
  • Generate Draw warns if one or more affiliations have not signed, but does not hard-block unless changed later.

8. Referee Management

  • Basic referee data is maintained in the Main Web Referees tab.
  • Assignments, final pool, and evaluations are handled in Referee Management.
  • External Referee Management connects to the same backend and should use the production URL by default.
  • Future roadmap: quicker visual evaluation entry, predefined comment chips, quota reduction, special match marking, and manual filters.

9. Delegation Sign-off

  • Available inside Main Web and as delegation_signoff_v35.html for tablet use.
  • Each approval captures representative name, confirmation, signature, timestamp, player snapshot, approval ID, and version.
  • Approval documents can be printed or saved as PDF.

10. Operations Tools

  • Cockpit: server monitoring, logs, services, terminal.
  • File Browser: upload and replace TMS files under /var/www.
  • PM2: sudo pm2 list, sudo pm2 restart kurash-tms --update-env, sudo pm2 save.
  • Use sudo for PM2 because production services currently run under root PM2.

11. Troubleshooting

  • 403: verify files exist and run permissions fix: chmod 644 /var/www/kurash-tms/*.html.
  • 502: confirm PM2 service is online and backend port 4010 is reachable.
  • Scoreboard not updating: check /api/ping, then reload Scoreboard and Main Web.
  • After upload: use hard refresh Ctrl + F5.

v35.6.7 Patch 4 - Scoreboard Operations Cleanup

  • Main Web scoreboard preserves the selected bout during live refresh.
  • External online scoreboard has a bout dropdown available inside fullscreen mode.

v35.6.7 Patch 5 - Referee Advanced Tools

  • Internal Special Match Marking: mark sensitive/high-level bouts from Referee Management. These marks are internal only.
  • Referee Participation Quota: set 100%, 75%, 50%, 25%, or 0% per referee.
  • Grace behavior: quota reduction is intended to affect assignments after the current bout and next bout when an active bout exists.
  • High-rated warning: reducing a referee with an average score of 90+ shows a confirmation warning.
  • Manual selection filters: hide 0%, hide reduced, final-pool-only, and minimum average score filters.
  • Visual markers: reduced quota referees show colored quota badges.
